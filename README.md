# Carbon Footprint Tracker

This simple carbon footprint tracker allows users to log activities and see how they impact their overall carbon footprint.

# Features Implemented

- **Activity Logging:** This feature allows users to log daily activities, categorizing them by type. Each activity has an associated carbon value, helping users understand their environmental impact.
- **Summary View:** Dashboard that provides the user's total number of logged activities and total carbon amount, as well as a bar graph of carbon usage over the last week and a pie chart breaking it down by activity category.
- **Resource Library:** Section with practical tips and resources for sustainable living, encouraging users to adopt eco-friendly habits.
- **Achievements:** This feature introduces gamification by creating achievements for reaching milestones, making the experience engaging and rewarding.
- **Local Storage:** All data is stored locally in the browser, ensuring users do not lose their progress/logged activities when they leave the page.

# Setup Instructions

To run the app, just do `npm install` and `npm run dev` in your terminal.
